## Decision

Each source gets its own translator that builds the canonical order by hand from an explicit allow-list of fields. Anything not listed is dropped, so data that must not travel cannot leak. TODO: one sentence on how you handled a pricing failure (the warnings you pass through).

## Consequences

- Pricing makes one sequential HTTP call per line item, with no cache and no timeout, so a slow pricing API makes the whole translation slow.
- The three product-id branches are hardcoded, so a fourth source with another id format needs a new branch.
- If the canonical schema gains a required field, all three translators break at once, since each builds the order by hand.
- An allow-list is safe against leaking data and brittle against schema change.
